# F-22 ADF 按键对照

译文体例对齐 DCS 中文飞行手册。键名保持原键盘刻字。原文 © Digital Image Design / Ocean，1997。

**注：** 数字键在「顶行数字」与「扩展键盘（小键盘）」上职能不同。驾驶舱内看各多功能显示器（MFD）时，用小键盘。

---

## 平视显示器（HUD）

| 按键 | 功能 |
| --- | --- |
| `H` | 循环平视显示器模式 |
| `SHIFT+H` | 循环平视显示器颜色（含姿态显示颜色） |
| `BACKSPACE` | 转入对地平视显示器，并循环对地武器 |
| `ENTER` | 转入对空平视显示器，并循环对空武器 |

### 顶行数字

| 按键 | 功能 |
| --- | --- |
| `1` | 转入仪表着陆系统（ILS）着陆平视显示器，并在预置无线电频率 1 上与机场通信 |
| `4` | 转入空中加油平视显示器，并在预置无线电频率 4 上与加油机通信 |

---

## 视角与智能摄像机

| 按键 | 功能 |
| --- | --- |
| `F1` | 在带平视显示器 / 不带平视显示器的虚拟驾驶舱之间循环 |
| `SHIFT+F1` | 检查六时方向（后方） |
| `F2` | 在内部视角与外部视角之间循环当前目标的视觉锁定（玩家→目标）。该键会覆盖其它视觉锁定 |
| `SHIFT+F2` | 外部视角，目标→玩家 |
| `F3` | 在内部视角与外部视角之间循环威胁视觉锁定（玩家→威胁） |
| `SHIFT+F3` | 外部视角，威胁→玩家 |
| `F4` | 在内部视角与外部视角之间循环对象视觉锁定（玩家→对象）。对象类型由 `F11`（浏览过滤）设定 |
| `SHIFT+F4` | 外部视角，对象→玩家 |
| `F5` | 在内部视角与外部视角之间循环僚机视觉锁定。该键会覆盖其它视觉锁定 |
| `SHIFT+F5` | 外部视角，僚机→玩家 |
| `F6` | 玩家掠过视角 |
| `SHIFT+F6` | 玩家环绕掠过视角 |
| `F7` | 玩家可移动外部视角（`RIGHT SHIFT` + 方向键移动摄像机） |
| `SHIFT+F7` | 循环固定外部视角：跟随、固定一、固定二、卫星 |
| `F8` | 循环导弹视角 / 挂架视角 |
| `F9` | 当前所选视觉锁定对象的可移动外部视角。`SHIFT` + 方向键环绕对象；`Z` 或 `SHIFT+Z` 在射程内对象间循环 |
| `SHIFT+F9` | 当前视觉锁定对象的固定外部视角 |
| `F10` | 所选对象的掠过视觉锁定 |
| `SHIFT+F10` | 所选对象的环绕掠过视觉锁定 |
| `F11` | 视觉锁定浏览过滤：空中 / 地面机动 / 地面固定目标 |

## 智能视角菜单

先按 `0` 打开智能视角菜单系统。

| 按键 | 功能 |
| --- | --- |
| `F9` | 保持 / 解除保持当前对象 |
| `F10` | 选择对象 |
| `F11` | 选择所属阵营 |

## 驾驶舱内视角

| 按键 | 功能 |
| --- | --- |
| `K` | 在广角 / 正常焦距之间循环 |

### 扩展键盘（小键盘）数字

| 按键 | 功能 |
| --- | --- |
| `1` | 防御多功能显示器 |
| `2` | 态势多功能显示器 |
| `3` | 攻击多功能显示器 |
| `4` | 综合通信与告警多功能显示器 |
| `5` | 前方多功能显示器与面板 |
| `6` | 人工地平仪多功能显示器 |
| `8` | 回到正常的 `F1` 平视显示器视角 |
| `0` | 系统多功能显示器 |

## 游戏控制

| 按键 | 功能 |
| --- | --- |
| `ALT+F1` | 联机帮助（游戏进行中） |
| `SHIFT+O` | 选项画面 |
| `DEL`（扩展键盘） | 打开游戏内地图 |
| `P` | 暂停 |
| `SHIFT+S` | 时间跳跃至下一事件 |
| `SHIFT+T` | 时间加速 开 / 关 |
| `SHIFT+A` | 进入 / 返回 ACMI |
| `ESC` | 退出；或在预警机（AWACS）任务中从 F-22 转到预警机 |

---

## 空中通信

| 按键 | 功能 |
| --- | --- |
| `TAB` | 在全部无线电频率上与僚机通话的菜单 |

### 顶行数字（通信）

| 按键 | 功能 |
| --- | --- |
| `1` | 在封闭频率 1 上与僚机和机场通话，并转入仪表着陆系统着陆平视显示器 |
| `2` | 在开放频率 2 上与僚机、预警机通话，以及广播与请求帮助 |
| `3` | 在封闭频率 3 上与僚机和预警机通话 |
| `4` | 在封闭频率 4 上与僚机和加油机通话，并转入空中加油平视显示器 |
| `5` | 向所有人发送玩家键入的报文 |
| `6` | 向僚机发送玩家键入的报文 |
| `Y` | 回答「是」 |
| `N` | 回答「否」 |
| `R` | 「请再说一遍」（重发上一份报文） |

## 航空电子

| 按键 | 功能 |
| --- | --- |
| `A` | 自动驾驶仪 开 / 关 |
| `E` | 电磁控制（EMCON）菜单 |
| `6` | 自动电磁控制 |
| `1`–`5` | 手动电磁控制 1–5 |
| `T` | 为当前所选武器建立射击清单（SHOOT LIST） |
| `X` | 手动向后循环射击清单 |
| `C` | 手动向前循环射击清单 |
| `F` | 循环所选武器的发射方式。对空：单发 / 连射；对地：单发 / 连射齐射 |
| `S` | 把当前视觉锁定的目标加入本机射击清单 |
| `M` | 把当前视觉锁定的目标加入僚机射击清单 |
| `Z` | 在固定目标、地面目标和飞机之间向前循环视觉锁定 |
| `L` | 循环 LANTIRN 模式：从动（攻击地面车辆）/ 自由（锁定框可套任何目标） |
| `Q` | 后退 1 个航路点 |
| `W` | 前进 1 个航路点 |
| `V` | 夜视 开 / 关 |
| `ALT+R` | ACMI 记录 开始 / 停止 |

## 飞机操纵

| 按键 | 功能 |
| --- | --- |
| `I` | 手动打开 / 关闭座舱盖 |
| `[` `]` | 循环左 / 右发动机 开 / 关 |
| `+` | 增大油门 |
| `-` | 减小油门 |
| `SHIFT++` | 油门收到全军用推力（100%） |
| `SHIFT+-` | 油门收到飞行慢车 |
| `TAB` 上方键 | 推力矢量（按住期间接通） |
| `,` `.` | 方向舵 / 前轮转弯 左 / 右 |
| `SHIFT+,` `SHIFT+.` | 左 / 右脚蹬刹车 |
| `B` | 减速板 开 / 关（空中为减速板；地面为减速板与机轮刹车） |
| `G` | 收放起落架 |
| `O` | 手动打开 / 关闭主武器舱门 |
| `D` | 自动改出并改平 |
| `BACKSPACE` | 循环对地武器，并转入对地平视显示器 |
| `ENTER` | 循环对空武器，并转入对空平视显示器 |
| `SPACE` | 发射 / 投放所选武器 |
| `;` | 手动投放箔条 |
| `'` | 手动投放红外诱饵弹串 |
| `INSERT` | 手动投放相应对抗器材 |
| `SHIFT+J` | 抛离菜单 |
| `1` | 抛离副油箱 |
| `2` | 抛离对地武器 |
| `3` | 抛离全部外挂 |
| `SHIFT+ESC` 再 `ESC` | 弹射 |
| `ALT+G` | 在 `F1` 视角显示 / 隐藏飞行员辅助符号 |

**注：** 对于 AIM-9X“响尾蛇”、AGM-65“小牛”以及自由落体炸弹，第一次按 `SPACE` 打开武器舱门，第二次按才发射或投放。

**注：** 油门在全军用推力后再按一次对应键，收到最大推力（本模拟为 140%）。
