# 玩家视角与智能视角

原书第 105–114 页。完整键位见《按键对照》。联机帮助与按键卡可交叉查阅。

## 玩家视角

可在虚拟驾驶舱内、机外与仪表特写之间选择。`F1` 循环带/不带平视显示器的虚拟驾驶舱。`K` 循环广角与正常焦距。

小键盘看各多功能显示器：1 防御、2 态势、3 攻击、4 综合通信与告警、5 前方、6 人工地平、0 系统、8 回到正常 `F1`。

## 视觉锁定（padlock）

把视线锁在选定目标或方向上，更接近真实观察。

| 键 | 作用 |
| --- | --- |
| `F2` / `SHIFT+F2` | 当前目标，内部/外部；外视目标→玩家。覆盖其它锁定 |
| `F3` / `SHIFT+F3` | 威胁 |
| `F4` / `SHIFT+F4` | 对象（类型由 `F11` 浏览过滤设定） |
| `F5` / `SHIFT+F5` | 僚机；覆盖其它锁定 |
| `F6` / `SHIFT+F6` | 玩家掠过 / 环绕掠过 |
| `F7` / `SHIFT+F7` | 可移动外视；循环固定跟随/固定一/固定二/卫星 |
| `F8` | 导弹 / 挂架 |
| `F9` / `SHIFT+F9` | 当前锁定对象的可移动/固定外视 |
| `F10` / `SHIFT+F10` | 所选对象掠过 / 环绕掠过 |
| `F11` | 过滤：空中 / 地面机动 / 地面固定 |
| `SHIFT+F1` | 检查六时方向 |

`Z` 在固定、地面与空中目标间循环锁定。`RIGHT SHIFT` + 方向键移动可移动外视摄像机。

## 智能视角

军方模拟称「隐身观察」。虚拟摄像机可挂到任意飞机或地面目标并串联成镜头。先按 `0` 打开智能视角菜单，再用 `F9` 保持/解除、`F10` 选对象、`F11` 选阵营。

**注** 智能视角与玩家视觉锁定共用部分功能键，以当前模式为准。
