# 机动、僚机与通信

原书第 87–98 页。

## 拖曳（Drag Left / Right）

双机中一架作诱饵向左或向右飞，敌机跟上后，另一架转到其后方攻击。视距外有时先诱向一侧再反向。口诀：先拖住鼻子，再踢屁股。

## 进攻分散（Offensive Split）

战斗展开队形中，一架吸引注意，另一架尽量不被发现地绕到背后。也可接在「目视识别与射击手」之后：长机目视并令僚机射击，敌人转向长机时，射击手低空、不被发现地急转爬升到敌后。

## 夹击 / 三明治（Sandwich / Bracket）

双机最老的把戏之一。被后方四分之一象限攻击的一架转向僚机相反一侧，把攻击者拉过去，僚机转到其后方，等第一架脱离危险区后用红外响尾蛇解决。

## 防御分散（Defensive Split）

对付后方同等数量来袭。一架拉高并试图环到攻击者后方（更耗能、更像猎物），另一架滚转急俯冲。低位僚机再拉起处理来袭，与正在把敌人拖下来的长机会合。

## 研磨机（Grinder）

美国空军战术：编队机动后齐射远程导弹，再迅速盘旋到较低高度脱离或重新集合，提高成功率、降低损失。可重复直到对方被消灭。见空对空「视距外」。

## 隐身突击

任务需要偷袭时，隐身是巨大资产，也便于在政治上保持「可否认性」。保持低电磁控制，用被动传感器与数据链瞄准。

## 诱饵、电子对抗、箔条与红外诱饵弹

都为阻止或扰乱来袭导弹，机理不同。

- 诱饵有两类，在雷达或红外上看都像载机：一类像巡航导弹沿预定航线飞离；一类是受攻在即放出的拖曳靶。
- 电子对抗形式很多，核心是让敌雷达看不清被干扰的飞机。
- 箔条是最后手段：大量铝箔条暂时迷盲导弹、战斗机或地面站雷达。
- 红外诱饵弹也是最后手段：强热源诱骗红外弹并迷盲红外搜索跟踪。

## 僚机指令

按 `TAB`，头盔左上角出现菜单。除 1 与 9 随上下文变化外，其余进入下级选项。

### 队形（选项 2 FORMATION）

有的翼尖靠翼尖，有的是大横向间隔的战斗展开。

| 队形 | 用法 |
| --- | --- |
| Card | 四机最有用，互相交叉掩护，如扑克牌四角水平散开 |
| Deuce | 专用于双机 SEAD：前机诱饵，后上方一架盯任何试图跟踪前机的雷达并射 HARM |
| Sweep | 横队，歼击机清场或全编队同时过海岸等障碍，分摊地面火力 |
| Strike | 纵队对地投放，间隔须防止飞进前方爆炸 |

## 游戏内语音

塔台、预警机、加油机与僚机有语音。可在选项中开关。综合通信与告警多功能显示器有文字转写。`Y` / `N` 回答是/否，`R` 请再说一遍。

## 无线电频率

| 频率 | 用途 |
| --- | --- |
| PUSH 1（顶行 `1`） | 封闭，机场 / 仪表着陆 |
| PUSH 2（`2`） | 开放，预警机、广播、求救 |
| PUSH 3（`3`） | 封闭，预警机 |
| PUSH 4（`4`） | 封闭，加油机 / 加油平视显示器 |

`TAB` 在全部频率上对僚机通话。`5` / `6` 向所有人或仅僚机发送键入报文。
