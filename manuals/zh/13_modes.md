# 快速作战、模拟训练与战区巡航

原书第 133–138 页。

## 快速作战

街机对抗：飞行动力学与航空电子与其它模块相同，但按击毁计分，误击己方重罚。从一开始就充满动作，约五小时。主界面进入后选想定即可。游戏中 `SHIFT+O` 打开选项。

## 模拟训练

与 DID 售予军方的训练软件同源。左上六块训练区，各含预制任务：

| 分区 | 内容 |
| --- | --- |
| Flight Training | 起降等基础 |
| Weapons Training | 瞄准与发射 |
| Free Flight | 从也门山地起、逆时针和平时期环游 |
| Air-to-Air Tactics | 空战训练 |
| Wingmen | 用好僚机 |
| AWACS Missions | 预警机指挥。可从预警机进入并驾驶显示上的任意 F-22 |

滚动列表点选任务，高亮为当前。CONFIRM 开始，CANCEL 回主菜单。Custom 用于日后加入的新任务。

右侧信息钮：个人日志（履历与勋章）、地图（航线叠在世界上）、简报、观察目标（对地任务）、攻击航线（对地编队路径）、ACMI（查看作为简报一部分的预制记录）。

简报也会出现在驾驶舱左上综合通信与告警多功能显示器。各课除必学内容外还有其它活动。此处学会的技能会带到战区巡航各中队；不必先完成，但很有帮助。成败按预设标准以百分比显示。

## 战区巡航

进入「实战」。三条想定难度与复杂度递增，地点与国家不同。各任务成败影响推进。初次看得见全部任务，但每条只能选第一课；完成后解锁下一课，直至可全部重玩。部分最终任务从预警机开始，可指挥全局并驾驶显示上的任意 F-22。

界面与模拟训练类似：左上选巡航，下列任务，CONFIRM / CANCEL，`SHIFT+O` 选项。右侧同样六钮。可能与该地区多种敌人交战，个别想定会打到其它 F-22。成败同样以百分比显示。
