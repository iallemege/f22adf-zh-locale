# ACMI（空战机动仪表记录）

原书第 99–104 页。用于任务中记录、讲评时回放位置与姿态。部分训练简报带预制记录。

## 模式

回放与录制。任务中 `ALT+R` 开始/停止记录；`SHIFT+A` 进出 ACMI。主界面 ACMI 按钮可打开任意已有记录。

## 界面与显示

主窗口加观察控制与视频控制。可选视角：

| 视角 | 作用 |
| --- | --- |
| Cockpit | 当前焦点飞机的飞行员眼位 |
| Spin | 绕焦点机连续旋转 |
| Satellite | 俯视 |
| Free | 按住鼠标左键拖动，环绕焦点机 |
| Track | 摄像机指向该机当前目标 |
| Side Track | 与该机及其目标成 90° |

主窗口左侧滚动条缩放观察距离（驾驶舱视角无效）；右侧滚动条改目标尾迹长度，可减杂乱或在目标很多时提高帧率。

## 视频控制

从左到右：回到起点、停止/暂停、播放或录制、四倍快进。旁有秒计时。回放时 FULL 全屏，SMALL 回到小窗。

## 目标选择

Next Plane / Last Plane 在记录中的飞机间移动焦点。物体轨迹旁有文字说明。可按类型过滤（空中、武器、高度等，见游戏内按钮）。

讲评时放慢、加速或冻结，对照自己的机动与武器投放。
