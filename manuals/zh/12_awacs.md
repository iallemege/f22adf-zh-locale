# 预警机（AWACS）

原书第 121–132 页。你在此战术控制雷达覆盖内的空战，识别并排列威胁，组织战斗空中巡逻（CAP）、拦截与近距空中支援（CAS），并处理救援、转场与再补给。双击 F-22 图标进入该机；未交战时 `ESC` 返回；被击落或弹射后自动返回。

## 指挥界面

左侧控制按钮过滤地图内容。三维窗口显示当前所选地图目标。其下信息窗列出该飞行或目标的已知数据；不明或在预警机距离外则无信息。Exit 回到模拟训练或战区巡航菜单（视从何处进入）。

右侧地图显示预警机雷达范围内、且被过滤器选中的交战要素：己方海陆空，以及距离内的敌方与中立。

## 地图过滤（控制面板）

| 按钮 | 作用 |
| --- | --- |
| Scale | 地图底边海里比例尺 |
| FEBA | 战斗前沿（FEBA） |
| Nations | 彩色地图与国名（默认开） |
| DTINS | DID 交互目标符号与文字（默认开） |
| Stylized | 点符号与示意符号切换；选中 NTIDS 时断开 |
| NTIDS | 北约目标识别符号；覆盖点/示意选择 |
| Air Defense | 地空导弹发射架、预警雷达、雷达与通信站；三维地图上显示地空导弹伞 |
| Airforce | 全部机场（默认开） |
| Routes | 己方航线与航路点 |
| Army | 军事基地及已知/己方地面部队。要看详细地面情况须有 E-8 联合星在空 |
| Navy | 海军基地及已知/己方海军 |
| Information Box | 鼠标下飞行的信息框，并在信息窗重复 |
| Time Skip / Time Warp | 时间跳跃 / 时间加速 |

另有三维暂停、比例与其它显示开关，以游戏内按钮为准。

## 用鼠标生成指令

在地图上点选飞行，再对其它飞行或目标下达指令。己方对己方、对中立、对敌、对不明的可用命令不同（护航、拦截、攻击、识别等）。报文窗口显示往来通信。

细节随任务变化；模拟训练的预警机课目专门练习这些操作。
