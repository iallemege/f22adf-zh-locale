## 射击清单

探测到的目标按交战顺序进入射击清单，可用按键自动建立，或在多功能显示器上手动点选。优先级按方位、类型与速度评估。按 `T` 为当前所选武器类型建立清单。

**注** 清单通常自动建立。也可用 `F2` 或 `F3` 视觉锁定目标再按 `S` 手动加入。这对 AIM-9X“响尾蛇”与 AGM-65“小牛”尤其重要。

也可在态势或攻击多功能显示器上把光标放到目标上单击，每次单击把该目标加入清单。武器按你点选的顺序交战。清单条目数与载弹量对应，每种武器各有一份清单。

**注** 自动清单仍可手工补到每枚武器都有目标。光标停在某目标上时，该多功能显示器左下角显示其信息。

### 循环目标

手动为默认：射击后按 `C` 向前、`X` 向后循环瞄准点。自动循环：到攻击多功能显示器按 Auto Cycle Targets。每发射一枚所选武器，下一枚自动对准清单中的下一个目标，可在 SHOOT 提示出现时连续发射。只有一次通过机会时，可在系统多功能显示器把所选武器设为齐射或连射：齐射一次打出全部所选武器；连射则每枚在信息齐备且进入射程时发射。齐射/连射枚数事先在系统多功能显示器设定，扣一次扳机开始序列。

### 与僚机共享目标

目标信息经编队内数据链（IFDL）共享。按 `F2` 或 `F3` 指定后，按 `TAB` → 3 Combat → 1 ENGAGE MY TARGET，或直接再按 `M`，让僚机交战该目标。

## 红外搜索跟踪（IRST）

高灵敏度红外摄像机，可把目标放大到前方多功能显示器，以便在远超目视距离上目视识别。扫描前方弧区及上下若干度。电磁控制 2 及以上与雷达协同，被引导到射击清单当前目标。使用 `F2` 视觉锁定时，红外搜索跟踪从动于飞行员视线。

电磁控制 1 时它成为机上主搜索跟踪设备，靠热辐射发现目标，是很隐身的获取手段。所得信息与其他传感器汇合，可引导所有制导空空与空地武器。

## 驾驶舱布局

全玻璃驾驶舱，主要包括：

- 平视显示器（HUD）
- 前方多功能显示器
- 综合通信与告警多功能显示器
- 防御多功能显示器
- 人工地平仪多功能显示器
- 攻击多功能显示器
- 态势多功能显示器
- 系统多功能显示器

## 平视显示器（HUD）

位于视线内、座舱盖前部内侧。`SHIFT+H` 在亮红、暗绿、亮绿、暗红之间循环颜色。`H` 循环五种模式。各模式共同信息包括：指示空速、速度矢量、当前电磁控制、海拔英尺、俯仰梯、罗盘带、下一航路点、航路点指向符、发动机功率、减速板状态、过载、当前无线电。

### 头盔显示器（HMD）

把当前平视显示器模式等信息投到头盔上。细节见联机帮助。

### 对空武器平视显示器

`ENTER` 或循环 `H` 进入。显示空战所需信息：射击清单第一架飞机的类型、接近速度、目标高度、目标距离（海里）、目标速度、本机马赫、当前所选武器射程条、敌机跟踪与优先级。

### 对地武器平视显示器

`BACKSPACE` 或循环 `H` 进入。显示机动或固定地面目标瞄准信息：炸弹下落角、下落线、当前武器、可用枚数、发射方式、目标循环、当前 LANTIRN 模式。

### 仪表着陆系统平视显示器

循环 `H` 进入。显示进近速度告警、仪表着陆系统标志、进近高度告警。

### 导航平视显示器

循环 `H` 进入。武器解除，显示外部/内部燃油状态等航路信息。

### 空中加油平视显示器

循环 `H` 进入。显示高度告警与加油状态。

## 指示目标

平视显示器与多功能显示器上的目标符号（原书为图示，此处用文字）：

| 符号含义 | 说明 |
| --- | --- |
| 敌机（亚音速 / 超音速） | 空中敌对接触 |
| 敌机雷达覆盖 | 扇区或圆 |
| 友机 / 不明飞机 | 空中友方或未知 |
| 敌舰 / 友舰 / 不明舰 | 海上目标 |
| 敌 / 友 / 不明地面机动 | 十字一类符号 |
| 敌弹 / 友弹 | 来袭或己方导弹 |
| 敌固定目标 | 地面固定 |
| 敌地空导弹或雷达阵地 | 圆表示雷达覆盖 |

瞄准顺序（平视显示器与多功能显示器相同四步）：正在跟踪 → 已锁定并进入射击清单 → 清单中的下一个 → 已对该目标发射武器。

## 多功能显示器（MFD）

驾驶舱共七块。细节见联机帮助。

### 综合通信与告警

单一模式：显示语音报文的文字转写、当前无线电频率，并穿插系统故障与告警。可循环无线电频率。

### 前方多功能显示器

两种模式：对空平视显示器时显示红外搜索跟踪的空中目标图像；对地时显示地面目标图像。周边还有电磁控制 1–5 与自动、起落架、主武器舱门、循环平视显示器、发动机左右状态、雷达锁定告警、来袭雷达制导导弹，以及 LANTIRN / 武器 / 红外图像、把图像锁定到所选武器、缩放等。

### 航空电子音响提示

女声告警，飞行员戏称为 “Bitchin' Betty”。在飞行员注意力在别处时给出重要提示。可在系统多功能显示器开关。另有合成音提示。

### 人工地平仪

显示人工地平与俯仰梯，并提供自动驾驶仪入口，便于仪表进近。

### 防御

两种模式：带敌方雷达与武器射程的传感器画面；交互式自动驾驶仪。可自动/循环电磁控制、投放诱饵无人机、箔条、六发红外诱饵弹串，增减传感器距离。

### 态势

两种模式：全局传感器态势；交互式自动驾驶仪。可显示地名、航路点、航路点编辑、只滤本机传感器/只地面/只空中，增减距离。活动地图衬在已探测目标之下。

### 攻击

四种模式：强调距离与高度的传感器画面；机腹 LANTIRN 电视图像（激光制导武器）；交互式自动驾驶仪；带摄像机的武器（如“小牛”）回传图像。可生成当前武器射击清单、显示距离数据、LANTIRN 图像/复位缩放/跟踪/模式/自动或手动循环。

### 系统

四种模式：对飞行员最紧要的一般系统；燃油；系统状态；交互式自动驾驶仪。

**注** 此处按钮改变发射方式：单发、连射、齐射。亦可增减发射枚数与发射间隔，开关语音告警，显示仪表着陆标志。

## 自动驾驶仪

可覆盖任务各阶段：滑行到跑道并自动起飞、沿航路点与预定航向、跟踪目标、保持速度、协助空中加油、着陆并滑回停机坪。空中或地面随时接通或断开。按 `A`。

起飞：须已获滑行许可并按 `Y` 回答，且自动驾驶仪处于起飞模式。

着陆：须已请求并获准着陆并按 `Y` 回答，且处于着陆模式。

加油：须已请求加油许可，并对 AFFIRM WEAPONS AND NOSE COLD 按 `Y`。在自动驾驶仪上选择加油，平视显示器应为加油模式，在加油机左后方占位。加油机发出 CLEARED PRE-CONTACT 后按 `A` 接通。

各主多功能显示器均可调用，模式包括：跟随航路点、跟随航向、跟随射击清单第一目标、保持设定速度、起飞、着陆、加油。
