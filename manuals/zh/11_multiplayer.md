# 多人游戏

原书第 115–120 页。1997 年连接方式针对 Windows 95 Direct Play 3。Steam 重制版的联机以当前客户端为准；下列按原书转写。

## 界面

左侧面板：加入已有对局（Join Game）或新建（New Game）。想定列表列出可用任务。当前玩家列表显示已加入者。

新建后底部三钮：Reject Player（从列表移除所选玩家）、Cancel（回上一屏）、Enter（进入玩家参数）。

玩家参数：选武器、选队伍。Cancel 返回；Enter 开始所选任务。

右侧：对局详情（当前所选任务简报）、聊天。

## 连接计算机

全体玩家须选同一 Direct Play 服务：

| 服务 | 用途 |
| --- | --- |
| Winsock IPX | 仅局域网 |
| Winsock TCP | 局域网与广域网 |
| Modem | 调制解调器 |
| Serial | 串口线 |

IP 地址、波特率等按操作系统提示填写。一方建局，其余加入。防火墙与 NAT 问题属重制版/系统范畴，原书未述。
