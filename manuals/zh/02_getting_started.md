# 入门

原书第 8–12 页。1997 年安装说明针对 Windows 95 与光盘版。Steam 2026 重制版从 Steam 启动即可，不必再装 DirectX 5。下列程序按原手册转写，供对照。

## 安装

将《F-22 Air Dominance Fighter》光盘插入光驱后，安装程序会自动运行。若本机已安装，可选择运行、更改配置或重新安装。

运行本模拟需要 DirectX 5 或更高版本。安装程序可按提示自动安装 DirectX 5。

安装步骤：

1. 放入光盘，安装程序自动启动。
2. 在版权窗口单击 Next 后，询问是否安装 DirectX 5。没有 DirectX 5（或更高）则无法运行，建议安装。
3. 选择安装类型：
   - Typical（典型）：拷贝全部数据。占用硬盘最多，载入最快。
   - Compact（精简）：只拷贝运行所需文件。游玩时必须把光盘留在光驱，载入较慢。
   - Custom（自定义）：由高级用户指定拷贝哪些文件。
4. 选择「开始」菜单快捷方式所在文件夹。不熟悉者建议保持默认并单击 Next。
5. 核对刚才的选项。满意则单击 Next 开始安装；否则反复单击 Back 回到要改的一步。
6. 文件拷贝进度由屏幕中央蓝条表示，到达右侧即完成。
7. 选择控制器。DID 建议使用飞行摇杆以获得最佳体验；没有摇杆可用键盘。
8. 声音选项：音效、音乐、语音。选择音乐则游玩时必须插入光盘。建议三项全部打开。
9. 询问是否阅读 `readme.TXT`。其中有手册付印后的更正，建议先浏览。
10. 单击 Finish，按提示重启 Windows，再按下一节启动。

### 启动

单击 Windows「开始」→「程序」→ DID → F-22 ADF → F-22 Air Dominance Fighter。

### 更改配置

再次放入光盘，选择 Change Setup of Installed Game，单击 Next 并按屏幕提示操作。

手册更正在 `readme.TXT`。

### 卸载

「开始」→「设置」→「控制面板」→「添加/删除程序」。

## 飞行摇杆与控制器

本模拟按 Windows 95 的飞行摇杆支持（文中写作 Direct Play）设计。凡支持该接口的摇杆与控制器均可使用，须在「控制面板」→「游戏控制器」中配置。

本游戏的 Direct Play 支持两轴与四个按钮。超过四个按钮的摇杆需要自行编程。

可编程摇杆：

1. 先用厂商工具给按钮分配功能。
2. 在「游戏控制器」中选择最接近的摇杆描述。多数摇杆只能定义两个按钮；可编程摇杆上未定义的按钮仍会发送已编好的键值。列表中没有你的型号时，选「添加新硬件」，Windows 可能询问标准端口或游戏卡端口，然后尝试自动检测。
3. 控制器窗口中状态应为 OK。否则换一项描述，或向厂商索取更新盘。
4. 检测成功后，校准向导会带你设置摇杆与按钮。

外设更新很快，具体型号支持见联机帮助与 `readme` 文件。DID 会尽可能以电子文档补充。

## 快速开始与界面

安装完成后，从「开始」菜单或桌面图标启动。首先出现登录画面，输入姓名与呼号。

### 主界面

| 项目 | 作用 |
| --- | --- |
| 快速作战（Quick Combat） | 街机对抗模块，立即交战 |
| 模拟训练（Simulator） | 训练模块，在接近真实的任务中学习 |
| 战区巡航（Tour of Duty） | 递进战役，任务互相衔接 |
| 多人（Multiplay） | 与网络上其他玩家进行对抗或协同 |
| ACMI | 以图形回放位置与姿态数据 |
| 选项（Options） | 用户可配置项。游戏中也可按 `SHIFT+O` |
| 制作人员（Credits） | 开发团队 |
| 帮助（Help） | 联机帮助（若已安装），内容与手册相近，交互图更多 |
| F-22 演示（Demo） | 演示模式 |
| 退出（Quit） | 返回桌面 |

**注** 主界面的 ACMI 按钮可以查看全部记录，不限于模拟训练或战区巡航里录下的片段。

进入各分界面后，选择任务或战役。飞行、航空电子、语音、战术与武器投放见本手册「F-22」章与联机帮助。有飞行模拟经验者也可直接试飞，不必读完全书。

手册与联机帮助互相参照，顺序与游戏模块一致。联机帮助便于跳转。需要更多说明时，原文指向：主菜单 → 帮助按钮。
